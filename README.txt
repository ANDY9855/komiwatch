WatchParty PHP + MySQL Starter

1. Import init.sql in phpMyAdmin to set up DB.
2. Adjust db.php credentials if needed.
3. Place project in XAMPP htdocs.
4. Visit http://localhost/watchparty/index.php

NOTE: The large PHP files (index.php, dashboard.php, party.php, sync.php, chat.php)
are included in the canvas above. Copy them into this folder manually.
